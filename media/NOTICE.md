# Exercise demo media

GIF demos in this folder are sourced from
[hasaneyldrm/exercises-dataset](https://github.com/hasaneyldrm/exercises-dataset)
(exercise motion media © [Gym visual](https://gymvisual.com/)).

SetPace ships one matched GIF per catalog exercise (22), with short HUD cues
aligned to that motion. Mapping: `dataset-map.json`.
